# research.ipynb

Практическое сравнение `u2net` и `isnet-general-use` (обе через `rembg`) на
трёх тестовых фото разной сложности.

Ноутбук уже выполнен — результаты (время работы, картинки до/после) видны
сразу при открытии, запускать заново не нужно.

Чтобы пересчитать:
```bash
pip install rembg onnxruntime pillow matplotlib jupyter
jupyter notebook research.ipynb
```

Выбранная по итогам модель (`isnet-general-use`) уже встроена в сервис.
