## Удаление фона: обзор подходов и выбор решения

| Решение | Плюсы | Минусы |
|---|---|---|
| U²-Net / rembg | Простая интеграция, self-hosted, быстро | Качество уступает более новым моделям на сложных границах |
| IS-Net | Хорошее качество сегментации, есть готовые веса | Требует отдельной настройки inference |
| BiRefNet | Высокое качество на задачах background removal, хорошие границы | Более тяжёлая модель |
| BRIA RMBG | Высокое качество из коробки | Для коммерческого использования требуется проверить/приобрести соответствующую лицензию |
| remove.bg / Photoroom / Clipdrop API | Минимум собственной инфраструктуры, хорошее качество | Платный API, зависимость от внешнего сервиса, изображения передаются третьей стороне |

Для MVP я бы начала с **IS-Net через rembg** (конкретно — веса `isnet-general-use`):

- готовый Python API;
- self-hosted inference;
- не нужно обучать модель;
- простой deployment через Docker;
- можно заменить модель без изменения API сервиса.

Если качества на сложных изображениях будет недостаточно, следующим кандидатом станет **BiRefNet**.

Коммерческую модель BRIA RMBG имеет смысл рассматривать отдельно после проверки условий лицензирования конкретных весов.

Практическое сравнение u2net и isnet-general-use на тестовых изображениях смотри в [`research/research.ipynb`](../research/research.ipynb).

## Оценка качества

Для сравнения моделей можно использовать следующие метрики:

- MAE — ошибка между предсказанной и эталонной маской
- F-measure
- S-measure
- IoU — для бинарной маски

Для тестирования подойдут DIS5K и HRSOD, при этом для продукта я бы дополнительно проверяла реальные пользовательские изображения: волосы, мех, мелкие детали, низкий контраст объекта с фоном и сложные края.
